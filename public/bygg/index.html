A15 er eit aktivt ingeniørprosjekt. Det finst enno ikkje eit bygd kamera, målt biletyting eller godkjend produksjonsmodell. Endelege produktrenderar kjem etter kontroll av form, optikk, elektronikk, montering og førsteartikkel.

01 / System

Tre delar. Eitt kamera.

Første integrasjonskandidat er ein skjermlaus Sony ILX-LR1 med E-fatning og RAW-opptak. Ein Linux-brubyggjar tek imot søkjarbilete og kontroll frå Sony sitt SDK. Telefonen snakkar med vår eigen opne IP-protokoll.

01 / Lys og opptak

Optikk + 61 MP kjerne

E-objektiv og Sony ILX-LR1. Kjøpt, proprietær biletkjerne. Det fysiske A15-huset skal ikkje bere objektivet via printa plast.

02 / Opent mellomlag

Linux-bru

Raspberry Pi, USB-kontroll og ein A15-protokoll som kan køyrast utan skya. RAW blir lagra på kameraet. Sony-SDK og lisens må kvalifiserast.

03 / Søkjar

iPhone

Same app over lokal Wi-Fi og USB-C via Ethernet-adapter. Telefonen viser førehandsvising og styrer kameraet; RAW-originalen ligg på kameraet.

03 / Delar som må skaffast

Det printaren ikkje kan lage.

Ei fullstendig produktliste må spesifiserast mot kontrollert CAD, straummålingar og monteringsprøver. Desse gruppene er nødvendige, men ingen pris blir dikta opp før eksakt del og mengd er valt.

Bilete og optikk

Sensor, lukkar, autofokuselektronikk og E-fatning ligg i ILX-LR1; objektivet blir kjøpt separat. Filterstabel og register blir målte på fysisk kjerne før skal og ring blir teikna ferdig.

Straum og lagring

Battericeller eller kvalifisert pakke, vern, lading, regulatorar, kablar og minnekort. Benken brukar eksterne forsyningar; den portable løysinga treng eige skjema og prøving.

Kontroll og samband

To-trinns utløysarbrytar, taktile hjul/brytarar, kontaktar, radiodel/antenne, statuslys og Ethernet-adapter for kablet iPhone. Knappedelar i formmodellen er berre visuelle.

Berande mekanikk

Metallberar, stativgjenger, remfeste, skruar, gjengeinnsatsar, pakningar og kabelavlasting. Printa skal er utside, ikkje dokumentert lastveg for linse, stativ eller rem.
